Build a full-stack AI Travel Planner web application with a modern UI and a multi-agent architecture.

### 🌍 CORE IDEA
The app allows users to input:
- Destination
- Budget
- Travel dates
- Preferences (luxury, adventure, food, culture, etc.)
- Number of travelers

Based on this, the system generates:
1. A detailed day-wise itinerary
2. Real-time (or near real-time) travel options (flights, trains, buses)
3. Hotel recommendations

NOTE:
- The app ONLY displays data. No booking functionality.
- Focus on optimization based on budget.

---

### 🧠 MULTI-AGENT ARCHITECTURE

Implement separate AI agents (modular functions/services):

1. **Planner Agent**
   - Generates a day-wise itinerary
   - Uses destination + preferences
   - Output: structured JSON itinerary

2. **Transport Agent**
   - Fetches flights, trains, buses
   - Uses free APIs:
     - Amadeus API (flights)
     - RapidAPI alternatives (train/bus data)
   - Filters options based on budget
   - If budget is LOW:
     - Prioritize trains/buses over flights

3. **Accommodation Agent**
   - Fetch hotels using:
     - Booking.com API (RapidAPI) OR
     - OpenTripMap / Geoapify / Google Places API
   - Filter by:
     - Budget
     - Rating
     - Location proximity
   - If budget is LOW:
     - Downgrade from 5-star → 3-star → budget stays

4. **Optimization Agent (IMPORTANT)**
   - Core decision-maker
   - Adjusts plan dynamically:
     - Switch flights → trains if cheaper
     - Reduce hotel cost
     - Optimize itinerary activities cost
   - Ensures total plan stays within user budget

5. **Coordinator Agent**
   - Combines all outputs
   - Produces final response:
     - Itinerary + transport + hotels
